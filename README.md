## What's Inside

### [Linux Command Line Basics](notes/linux-command-line-basics.md)
Operating system fundamentals, the Linux kernel, terminal vs 
shell, basic navigation, file operations, user and group 
management, process control, systemd services, SSH, and package 
management — everything needed to be fully comfortable in a 
Linux terminal.

## Topics Covered
- What Linux is and how the kernel works
- Terminal, shell, and prompt fundamentals
- File navigation and manipulation (`ls`, `cd`, `cp`, `mv`, `rm`)
- User and group management (`adduser`, `passwd`, `id`, `sudo`)
- File permissions and the Linux directory structure
- Process management and job control (`ps`, `kill`, `jobs`, `fg`/`bg`)
- systemd services and daemons
- Networking basics (`ip a`, `netstat`, interfaces, MAC addresses)
- SSH remote access and key-based authentication
- Package managers (`apt`, `snap`)
